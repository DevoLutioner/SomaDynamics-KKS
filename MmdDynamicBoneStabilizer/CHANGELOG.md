# Changelog

## 1.2.2-KKS

- 独立 KKS 仓库（DevoLutioner/SomaDynamics-KKS）首次发布：与 KK 版共用同一份源码，
  依赖 GUID 为 `Countd360.CharaAnime.KKS`；目标框架 net48（与 KKS CharaAnime
  程序集目标一致），游戏根目录默认 `H:\KKS\KKS`，产物为
  `MmdDynamicBoneStabilizer-KKS-v<版本>`。
- 已在 KKS 本地沙盒 CharaStudio 验证：插件加载正常，缺失依赖错误消失。

## 1.2.2

- 强制重置前校验 DynamicBone 与 DynamicBone_Ver02 粒子列表、父索引及父变换，避免作者异常链触发 `ArgumentOutOfRangeException`。
- 单条异常链只隔离强制重置，不再中断同角色其他头发、衣物、裙摆物理链的稳定处理。
- 每条异常链只记录一次诊断，避免跳转检测期间周期性异常日志和卡顿。

## 1.2.1

- 修复短保持时间导致运动稳定在启用/停用之间反复切换、造成裙骨与碰撞参数卡顿的问题。
- 新增默认开启的持续稳定模式：角色首次运动后保持稳定，直到角色移除或插件停用。
- 普通运动的跳转重置增加 30 帧冷却，且首次激活不再把大动作误作跳转重置。
- DynamicBone 到角色的归属改为缓存查询，移除每根物理链每帧遍历全部角色的开销。
- 组件刷新从每 120 帧降频到每 1800 帧，并只在激活或刷新时应用稳定参数。
- 角色发现扫描从每 120 帧降频到每 600 帧，减少大型工作室场景的周期性尖峰。

## 1.2.0

- 稳定触发从“仅 MMD 播放”扩展为自动检测所有工作室人物运动。
- 通过身体根、胯、头部锚点识别工作室动画、IK/节点移动和 MMD 之外的姿势变化。
- 新增位置、旋转阈值及停止后的保持帧配置，默认过滤浮点噪声并避免动作间隙反复启停。
- 普通人物运动沿用游戏原有 DynamicBone 解算顺序；MMD 仍在姿势写入后进行专用手动解算。
- Unity Cloth、裙骨碰撞稳定及跳帧补偿现在只作用于当前运动中的角色，静止后恢复作者参数。
- 插件、项目与发布脚本版本同步升级为 1.2.0。

## 1.1.0

- 针对 KKPE/裙摆球形碰撞体造成的 MMD 高频“穿入—推出”抖动增加专用稳定。
- 仅让识别到的裙骨链逐渲染帧求解，并临时缩小其引用球体半径；停止 MMD 后完整恢复。
- 激活日志新增 `skirtChains` 与 `skirtSpheres`，便于确认衣物是否被正确识别。
- 作为 Soma Dynamics 1.0 的推荐配套插件同步发布，并补充职责边界、兼容性和诊断说明。
- 发布脚本默认版本与程序集统一为 1.1.0，构建前清理暂存目录并输出 SHA256。

## 1.0.2

- 新增 Unity Cloth 稳定模式，覆盖使用原生布料系统而非 DynamicBone 的裙装。
- MMD 激活时限制衣物世界速度/加速度注入、增加最低阻尼并启用连续碰撞。
- 播放开始和真实跳转时调用 `ClearTransformMotion`，避免旧变换速度继续推挤衣服。
- 停止或移除 MMD 控制器时恢复衣物作者原始参数。

## 1.0.1

- 修复正常舞蹈时发根和衣摆旋转被误判成切歌，导致物理链每帧重置的问题。
- 跳转检测改用身体根、胯、头部三个稳定 MMD 锚点。
- 全链重置增加30帧冷却，每次跳转最多执行一次。
- 激活日志改为报告稳定锚点数量，移除加载阶段不准确的瞬时 FPS。

## 1.0.0

- 自动检测 CharaAnime 的 MMD 姿势控制器。
- 将头发、衣物及饰品 DynamicBone 排到 MMD 姿势写入之后解算。
- 兼容 Dynamic Bones Fix 22.1，选择性恢复高帧率跳帧补偿。
- 播放启用、切歌和拖动进度后自动重置陈旧粒子状态。
- 默认零调参，仅提供安全恢复阈值和诊断日志开关。
